What changes

Specific fixes this concept makes to the current site.

Each point below comes from a check of the firm’s live site, not from a template.

  • 01The live homepage’s page title is just “Home Page,” and its description tag says the same, so a search result shows no firm name, city or practice. This page is titled with the firm’s name and location.
  • 02The current page has no mobile viewport tag, so on a phone it renders at desktop width and has to be pinched and zoomed. This page reflows from 390px up.
  • 03Leftover builder text (“Your Subtitle text”) is still visible on the live page, and two of its three images have no alt text. Both are cleaned up here.
  • 04The site has no structured data. This page carries LegalService, Person and FAQ markup built only from facts on the firm’s own site.
